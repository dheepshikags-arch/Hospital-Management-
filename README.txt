1. Install XAMPP, start Apache + MySQL.
2. Copy this folder to C:\xampp\htdocs\hms
3. phpMyAdmin > Import > schema.sql
4. Open http://localhost/hms/setup.php once (creates demo users + demo data), then DELETE setup.php
5. Open http://localhost/hms/ . Demo logins: admin/admin123, doctor/doctor123, reception/reception123
(Edit DB credentials in config.php. Lucide icons load from a CDN, so internet is needed for icons.)
